## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing |
| md | 16px | Default element spacing |
| lg | 24px | Section padding |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: Touch targets minimum 44px (interactive elements: send button, list tiles)

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #FAFAFA | Background, surfaces |
| Secondary (30%) | #FFFFFF | Cards, DM tiles, message bubbles |
| Accent (10%) | #3BB77E | Send buttons, unread badges, active states |
| Accent (Instructor) | #7B5EA7 | Instructor DM tiles, role badges, message bubbles |
| Destructive | #D32F2F | Delete actions, error states |

Accent reserved for: send buttons, unread count badges, instructor-specific UI elements (tiles, bubbles, role badges), active navigation states. Never use accent for non-interactive text or backgrounds.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (send) | Send |
| Primary CTA (open DM) | Open |
| Empty state heading | No direct messages |
| Empty state body | Direct messages with instructors and students will appear here. Join group chats to auto-add instructor contacts. |
| Error state (messages) | Failed to load messages. Check your connection and try again. |
| Error state (DM list) | Failed to load conversations. Pull down to retry. |
| Destructive confirmation (delete message) | Delete Message: This message will be permanently deleted for all participants. Are you sure? |
| Destructive confirmation (delete DM) | Delete Conversation: This will permanently delete the conversation and all its messages. Are you sure? |
